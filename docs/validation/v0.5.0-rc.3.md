The fixture now explicitly preserves that prerequisite; all six final jobs pass. The [first VM run](https://github.com/fuyifu2024/linux-factory-reset/actions/runs/43577697701) caught a real regression: native Zenity file choosers reject custom button-label options. Source `2760bd4` omits those options for file pickers, adds a regression fixture and passes the fresh full GUI restoration above. Neither initial failure is counted as a restoration pass. / 首轮检查发现 slim 容器缺少 GTK 翻译，后保留依赖；首轮真实虚拟机又发现文件选择器拒绝自定义按钮文字，最终源码已修复并通过完整恢复，失败记录不冒充通过。
