# v0.5.0 validation / 验证记录

The stable recovery scope is Ubuntu 26.04 UEFI VMs. AMD64 covers GUI automatic preparation and full offline recovery. ARM64 covers CLI import of the prepared profile and full offline recovery. The [November VM acceptance](recovery-readiness.md) records both end-to-end runs and the validated disk layouts. The final release build changes version metadata and user-facing release scope wording. The recovery engine and first-user setup are unchanged from the tested November runtime.

稳定恢复范围为 Ubuntu 26.04 UEFI 虚拟机。AMD64 验收覆盖图形界面自动准备及完整离线恢复。ARM64 验收覆盖命令行导入已准备资料及完整离线恢复。两条路径及实际布局见 [11 月验收](recovery-readiness.md)。正式构建更新版本号及界面支持范围说明，恢复引擎与首次开户逻辑沿用已通过验收的实现。

The VM runs predate the final version and release-scope wording changes. Exact-artifact installation and upgrade ran on the final packages. No compilation or restore ran on the user's Raspberry Pi. Physical-device recovery and other distributions' recovery remain experimental. The Ubuntu AMD64 desktop test covered package installation and the default graphical target. Graphical sign-in and other distributions' desktop installation remain unverified.
