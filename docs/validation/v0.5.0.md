# v0.5.0 validation / 验证记录

The stable recovery scope is Ubuntu 26.04 UEFI VMs. AMD64 covers GUI automatic preparation and full offline recovery. ARM64 covers CLI import of the prepared profile and full offline recovery. The [November VM acceptance](recovery-readiness.md) records both end-to-end runs and the validated disk layouts. The final release build changes version metadata and user-facing release scope wording. The recovery engine and first-user setup are unchanged from the tested November runtime.
