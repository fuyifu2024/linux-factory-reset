## Limits / 限制

Only flat ext4 root + dedicated FAT ESP, standard GRUB, writable UEFI variables and Secure Boot already disabled are in scope. Generic sources are base/server images without a desktop. Btrfs targets, LVM, encryption, extra system/data partitions, shared/OEM ESPs, automatic installer-ISO deployment and Mint are unsupported. VM evidence does not validate physical hardware or every ARM board. Native Raspberry Pi boot retains its separate older flow.

The interruption test covers a durable WRITING state after a completed rollback copy with intact ESP/recovery storage. It does not establish recovery from arbitrary disk corruption, every possible interruption point, secure erasure or A/B boot management. The real GUI test uses Zenity and a genuine polkit agent; it does not substitute shell mocks for the application or authorization path.

范围限定为 ext4 根分区、专用 FAT ESP、标准 GRUB、可写 UEFI 变量及已关闭的 Secure Boot。虚拟机通过不等于真机兼容；断电验收也不是任意存储损坏和任意中断位置的保证。通用来源不带桌面，原生树莓派引导仍是独立的旧路径。
