# v0.5.0-beta.2 validation / 验证记录

## Candidate checks / 候选版本检查

Native build/install and Ubuntu 26.04 compatibility results will be recorded here before publication. / 发布前记录原生构建、安装及 Ubuntu 26.04 兼容性结果。

New regression coverage exercises real permission denial as an ordinary user in disposable containers, GUI guidance for missing/inaccessible state, CLI and GUI diagnostic export, the report's explicit field allowlist, private file permissions, and refusal to overwrite existing files or symlinks. No reset is armed in these tests. / 新增回归在可丢弃容器中以普通用户触发真实权限拒绝，验证界面提示、终端与界面诊断导出、字段白名单、私有文件权限、拒绝覆盖及符号链接；测试不设置恢复标记。

## Retained restoration baseline / 沿用恢复基线

The offline restoration, rescue, first-user and firmware-writing code is unchanged from the published Beta.1 tag. No new full guest restoration is claimed for Beta.2. Consult the [Beta.1 record](v0.5.0-beta.1.md) for exact scope and evidence, including Ubuntu 26.04 AMD64 real GUI, two consecutive restores and interrupted-write rollback, plus Ubuntu 26.04 ARM64 restore/reboot/new-user/password-authenticated sudo. / 离线恢复、救援、首次开户和固件写入代码相对 Beta.1 发布标签未变。本次不声称重新执行完整客体恢复；沿用记录包括 Ubuntu 26.04 AMD64 真实界面、连续恢复及断电回退，以及 ARM64 的恢复、重启、首次开户和密码认证 sudo。

Physical hardware and full Fedora ARM64 restoration remain unverified. Existing filesystem/layout restrictions still apply. / 物理硬件和 Fedora ARM64 完整恢复仍未验收，文件系统与分区布局限制继续适用。
