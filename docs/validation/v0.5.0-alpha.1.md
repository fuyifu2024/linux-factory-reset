## Source binding / 源码绑定

Ubuntu normal/power-cut runs use `3dcb553`, Fedora normal uses `2ba44db`, and Debian regression/latest Fedora failure use `8a1709b`. The later `6d18356` change adds a tested, read-only shared/OEM-ESP rejection before existing recovery paths; it does not change file reconciliation. Final builds below use commit `0de1493f518f1195a289e3e30ad9a59d8162c609`; the release tag adds evidence only, with unchanged application/recovery code. All final runtime changes are covered by the listed normal/rollback tests; the native Ubuntu shell adjustment does not affect Fedora's dracut/Bash runtime.

## Limits / 限制

Targets are flat ext4 root + dedicated FAT ESP, standard GRUB, writable UEFI boot variables, Secure Boot already disabled. Generic sources have no desktop. Btrfs target, LVM, encryption, extra system partitions, shared/OEM ESP and arbitrary physical hardware are unsupported. ARM guest boot is unverified. The power-cut test establishes recovery from a specific interrupted write state with an intact recovery disk and ESP; it does not inject storage corruption or claim arbitrary power-loss/firmware guarantees, failure during every rollback/cleanup instruction, secure erasure or A/B boot management. Native Ubuntu Pi boot does not gain this UEFI rescue/rollback protocol.
