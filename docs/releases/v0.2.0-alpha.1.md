## 中文

**Debian + Ubuntu，ARM64 不限树莓派。** 主程序继续使用 C++20，离线恢复使用 Shell。仓库、包和命令仍名为 `ubuntu-reset`，兼容旧版入口。

本版新增：

- Debian 恢复资料与目标检测，支持 Debian 12 / 13 的构建和安装包。
- 通用 `arm64-uefi` 恢复路径：适用于满足布局的 ARM64 服务器、UEFI VM、ARM64 电脑及开发板；使用 UEFI 的树莓派同样适用。
- Debian 的 `EFI/debian`、Ubuntu 的 `EFI/ubuntu` 引导指针，以及 ARM64 `grubaa64.efi` / x86_64 `grubx64.efi` 的区分。
- 发行版/CPU 匹配检查、schema 2 元数据，并继续读取旧版 Ubuntu schema 1。
- 中文/英文 README 和发布说明；Ubuntu 24.04、Debian 12、Debian 13 × ARM64/amd64 共六组构建、测试、DEB 打包及隔离容器安装检查。

**下载选择：**先按系统选择 `ubuntu24.04`、`debian12` 或 `debian13`，再选择 `arm64` 或 `amd64`。每组有动态链接的原生二进制和包含配套脚本的 `.deb`；完整功能推荐 DEB。`SHA256SUMS` 覆盖所有上传的二进制/安装包。发行页底部 `Source code (zip/tar.gz)` 是该版本完整源码。

**恢复源与限制：**Debian、通用 ARM64 和 x86_64 使用管理员/厂商制作、匹配设备且可信的已安装系统 `.squashfs`，不是自动导入任意官方 ISO，也不会自动下载通用 Debian 桌面安装源。要求 UEFI+GRUB、普通 ext4 根分区、FAT ESP 和独立 ext4 恢复分区。原生 Ubuntu Pi 5 的官方镜像下载/验签功能保留。非 UEFI 的 U-Boot/extlinux 等板卡布局仍需专门适配。

这是实验版。文件树恢复、资料生成、引导指针处理和打包/非破坏性安装经过自动检查；**真实硬件完整重启恢复、首次开户、物理 BIOS 重置和断电恢复仍未验收**。仅在可丢弃系统上测试。开发期间没有对工作电脑执行系统恢复、重启或 BIOS 重置。

## English

**Debian and Ubuntu, with ARM64 support beyond Raspberry Pi.** The main application remains C++20; offline recovery uses Shell. Repository/package/CLI names remain `ubuntu-reset` for compatibility.

New in this release:

- Debian target/profile detection, with Debian 12/13 builds and packages.
- Generic `arm64-uefi` recovery for compatible ARM64 servers, UEFI VMs, computers and boards; UEFI-booted Raspberry Pis use the same path.
- Distribution-aware `EFI/debian` / `EFI/ubuntu` pointers and architecture-specific `grubaa64.efi` / `grubx64.efi` loaders.
- Distribution/CPU matching, schema 2 metadata, and legacy Ubuntu schema 1 compatibility.
- Chinese/English README and release notes; six CI combinations covering Ubuntu 24.04, Debian 12 and Debian 13 on ARM64/amd64, including build, tests, DEB packaging and isolated non-destructive installation checks.

**Choose downloads by distribution first:** `ubuntu24.04`, `debian12` or `debian13`; then CPU: `arm64` or `amd64`. Each combination provides a dynamically linked native executable and a DEB containing companion scripts. Use the DEB for complete functionality. `SHA256SUMS` covers all uploaded binaries/packages. GitHub's `Source code (zip/tar.gz)` assets contain the complete tagged source.

**Recovery sources and limits:** Debian and generic ARM64/x86_64 require a trusted, device-compatible installed-system Squashfs profile produced by an administrator/OEM. This is not automatic arbitrary ISO import or automatic generic Debian desktop-image download. UEFI+GRUB, plain ext4 root, FAT ESP and separate ext4 recovery storage are required. The existing native Ubuntu Pi 5 official-image download/signature-verification adapter remains available. Native non-UEFI U-Boot/extlinux and other board-specific boot layouts need dedicated adapters.

This is an experimental release. Automated checks exercise file-tree restoration, profile creation, boot-pointer relocation and packaging/non-destructive installation. **Real hardware reboot recovery, first-user setup, physical BIOS defaults reset and power-loss recovery remain unvalidated.** Use disposable test systems. Development did not restore/reboot the working computer or reset its BIOS.
