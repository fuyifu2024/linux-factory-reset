## 中文

本次进入限定范围的公开测试：Ubuntu、Debian、Fedora 的官方镜像下载和恢复，主程序使用 C++20，恢复阶段保留少量 Shell。新增 ARM64 UEFI 串口适配，修复回退完成后重复取消的 EFI 启动项处理，并提供中英双语公测指南和问题模板。

下载后按 [公测指南](../beta-testing.md) 在可丢弃虚拟机中测试；具体通过的系统、架构、连续恢复、真实 GUI 与断电回退结果以 [Beta 验收记录](../validation/v0.5.0-beta.1.md) 为准。构建安装检查和实际重启恢复测试分别列出。

**公测范围：** 平铺 ext4 根分区、专用 FAT ESP、标准 GRUB、AMD64/ARM64 UEFI，Secure Boot 已关闭，另有已挂载的 ext4 恢复盘。恢复会删除全部旧用户及目标系统上的个人文件。通用自动来源为无桌面的 Ubuntu Server / Debian NoCloud / Fedora Cloud Base，恢复后在控制台新建管理员；不会精确重建历史桌面安装。

尚不支持 Btrfs 目标、LVM、加密、额外 `/boot` 或 `/home` 分区、共享/OEM ESP、Mint、安装 ISO 自动部署。不会自动分区、格式化或重置 BIOS。原生非 UEFI 板卡与物理硬件兼容性须单独验证；树莓派原生引导路径不属于本次 UEFI 回退验收。恢复不是磁盘安全擦除，也不保证任意硬件故障或任意断电位置均可恢复。

发布页包含源码、八个 AMD64/ARM64 独立二进制、六个 DEB、两个 RPM 和 `SHA256SUMS`。独立二进制需要对应发行版的运行库；Ubuntu 26.04 使用已单独验证的 Ubuntu 24.04 包。安装后以普通用户运行 `linux-factory-reset gui`，原 `ubuntu-reset` 命令仍兼容。

## English

This release opens a scoped public Beta for official-image download and recovery on Ubuntu, Debian and Fedora. The application remains C++20 with small offline Shell components. It adds ARM64 UEFI serial-console handling, fixes EFI-entry cleanup when cancelling again after rollback, and provides bilingual testing and feedback instructions.

Follow the [public testing guide](../beta-testing.md) in a disposable VM. The [Beta acceptance record](../validation/v0.5.0-beta.1.md) identifies the exact tested systems, architectures, repeated resets, real GUI flow and interrupted-write rollback. Build/install checks are recorded separately from actual guest reboots and recovery.

**Scope:** plain ext4 root, dedicated FAT ESP, standard GRUB, AMD64/ARM64 UEFI, Secure Boot already disabled, and another mounted ext4 recovery disk. Reset deletes all old users and personal files on the target system. Generic automatic sources are Ubuntu Server / Debian NoCloud / Fedora Cloud Base without a desktop. Create a new administrator at the local console; this does not reconstruct the exact historical desktop installation.

Btrfs targets, LVM, encryption, separate `/boot` or `/home`, shared/OEM ESPs, Mint and automatic installer-ISO deployment remain unsupported. No automatic partitioning, formatting or BIOS reset. Native non-UEFI board boot and physical hardware require separate validation; native Raspberry Pi boot is outside this UEFI rollback acceptance. This is not secure erasure or a universal hardware/power-loss guarantee.

Assets include source, eight AMD64/ARM64 standalone binaries, six DEBs, two RPMs and `SHA256SUMS`. Standalone executables need matching distribution libraries. Ubuntu 26.04 uses the separately verified Ubuntu 24.04 package. After installation run `linux-factory-reset gui` as a regular user; `ubuntu-reset` remains compatible.
