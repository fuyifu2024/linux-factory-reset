# v0.5.0 — First stable release / 首个正式版

## 中文

v0.5.0 的稳定恢复范围是 **Ubuntu 26.04 UEFI 虚拟机**。要求标准 GRUB、普通 ext4 根分区、独立 FAT EFI 系统分区、单独的 ext4 恢复盘，以及已关闭的 Secure Boot。

| 架构 | 已验证流程 |
| --- | --- |
| AMD64 | 图形界面自动下载、准备、预览、取消及完整离线恢复 |
| ARM64 | 命令行导入已转换恢复资料，完成独立救援启动、离线恢复和重启 |

两条流程均验证了旧账号与测试文件删除、新管理员开户、密码认证 sudo 及临时回退副本清理。**恢复会删除目标系统上的旧账号、个人文件、额外软件和设置。** 建议先在可丢弃的虚拟机里体验。

英语、简体中文、印地语、西班牙语和阿拉伯语可自动识别或手动切换。常见下载、镜像校验和授权报错会给出当前语言的处理提示，并保留系统原文。通用官方恢复源启动到文本控制台，可在开户后选择安装桌面。Ubuntu AMD64 已验证桌面包安装和图形启动设置，图形登录和其他发行版的桌面安装待实测。

真机和其他发行版的恢复仍属实验性。安装 ISO 可下载。自动部署 ISO、Btrfs 目标、加密盘、LVM、RAID、独立 /boot 或 /home 及共享 EFI 分区暂未支持。

Ubuntu 26.04 请选择 Ubuntu 24.04 构建的同架构 DEB。发布页还提供 Debian 12/13 DEB、Fedora 45 RPM、独立二进制、源码归档及 SHA256SUMS。

## English

The stable recovery scope for v0.5.0 is **Ubuntu 26.04 UEFI virtual machines** with standard GRUB, a plain ext4 root, a dedicated FAT EFI system partition, a separate ext4 recovery disk, and Secure Boot disabled.

| Architecture | Validated workflow |
| --- | --- |
| AMD64 | GUI download, automatic preparation, preview, cancellation, and complete offline restoration |
| ARM64 | CLI import of a prepared profile, independent rescue boot, offline restoration and reboot |

Both workflows verified old-account and test-file removal, a fresh administrator, password-authenticated sudo and cleanup of temporary rollback copies. **Reset deletes the target system's old accounts, personal files, additional software and configuration.** Try it in a disposable VM first.

The interface supports automatic detection or manual selection of English, Simplified Chinese, Hindi, Spanish and Arabic. Common download, image verification and authorization failures provide localized guidance with the original diagnostics. Generic official recovery sources boot to a text console. Desktop installation is optional after account creation. Package installation and graphical startup settings were verified on Ubuntu AMD64. Graphical sign-in and desktop installation on other distributions remain untested.

Recovery on physical devices and other distributions remains experimental. Installer ISOs can be downloaded. Automatic ISO deployment, Btrfs targets, encryption, LVM, RAID, separate /boot or /home, and shared EFI partitions remain unsupported.

For Ubuntu 26.04, choose the Ubuntu 24.04-built DEB for your architecture. Debian 12/13 DEBs, Fedora 45 RPMs, standalone binaries, source archives and SHA256SUMS are also available.
