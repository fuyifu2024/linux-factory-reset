# v0.5.0-rc.3 — Five interface languages / 五语言界面

English · 简体中文 · हिन्दी · Español · العربية

## 中文

- 新增五套内嵌语言文案，覆盖菜单、常见状态、兼容性检查、准备阶段、下载摘要、帮助和清空警告；自动识别系统语言，也能在界面中切换并保存偏好。
- 阿拉伯语采用实际 GTK 从右向左布局；安装包声明 locale 依赖，Debian 精简环境可在用户缓存生成所需 locale。Noto 字体推荐依赖帮助显示中印阿文字。
- 五种语言统一使用精确口令 `ERASE-ALL-USERS`，提权后台接收明确语言参数。旧版中文口令不再接受，任何翻译或错误输入均不能替代确认。
- 新增文案占位符校验、五语言清空确认/偏好测试，以及真实 GTK 方向检测和截图检查。

这是正式版候选，不是新增硬件支持的声明。原始系统报错、系统授权窗口和恢复后操作系统的首次开户控制台仍遵循其来源语言。恢复引擎和布局支持边界沿用 RC.2；物理硬件及新版完整 ARM64 恢复验收仍待完成。请先在可丢弃虚拟机中测试。

## English

- Five embedded catalogs cover application menus, common state errors, compatibility checks, preparation stages, download summaries, help and destructive warnings. Automatic language detection and a persistent manual selector are included.
- Arabic uses actual GTK right-to-left layout. Packages declare locale prerequisites; minimal Debian installations can generate the Arabic locale in a private user cache. Noto fonts are recommended by DEBs.
- All languages require the exact `ERASE-ALL-USERS` token. The selected language is explicitly forwarded to privileged operations. The former Chinese token is no longer accepted; translated or incorrect input cannot authorize deletion.
- New checks cover catalog/placeholder parity, five-language confirmations/preferences and actual GTK rendering/direction with screenshots.

This remains a release candidate. Raw OS diagnostics, system authentication dialogs and the restored OS's first-user console follow their original/system language. The recovery engine and supported layouts retain RC.2's limits; physical hardware and fresh full ARM64 restoration under the current preflight remain unverified. Test in a disposable VM first.
