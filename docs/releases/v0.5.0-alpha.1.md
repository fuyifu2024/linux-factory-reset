# Linux Factory Reset v0.5.0-alpha.1

## 中文

本次加入 Ubuntu 通用 UEFI 的官方自动恢复源、独立救援与写入失败/中断回退，以及真正的 Fedora dracut 恢复引擎。主程序保持 C++20；统一支持 AMD64 / ARM64，无需用户手填官网镜像地址。

Ubuntu 26.04、Debian 13、Fedora 45 的 AMD64 UEFI 云端虚拟机已实际完成自动下载、校验、离线恢复、重新开机、旧账号/测试文件清除、新管理员创建及真实 sudo 检查。Fedora 保持 SELinux Enforcing；首次开户兼容 kmscon 控制台。ARM64 有原生构建和真实官方镜像转换证据，尚未验证客体启动或物理硬件。故障结果与构建/产物来源见[完整验收记录](../validation/v0.5.0-alpha.1.md)。

恢复时临时安装独立 EFI 入口，并把恢复内核/initramfs 存放在另一块 ext4 恢复盘。离线保存回退副本后才修改 root/ESP；写入失败回退，恢复阶段记录支持中断后处理。正常完成后删除临时个人资料及宿主恢复副本。共享其他系统/OEM 引导文件的 ESP 在恢复前拒绝处理。

**预览版限制：** 当前目标必须是普通 ext4 根分区 + 专用 FAT ESP、标准 GRUB，Secure Boot 已关闭。不会自动分区、格式化或关闭 Secure Boot。通用自动源是 Ubuntu Server / Debian NoCloud / Fedora Cloud Base，**没有桌面，不会精确还原原桌面安装**。Fedora Btrfs 来源能转换，不代表支持 Btrfs 目标；LVM、加密、额外系统分区、ISO 自动安装、Mint 仍未支持。原生 Ubuntu Pi 路径暂未加入此 UEFI 回退协议。不是安全擦除、A/B 系统或任意硬件/断电事务保证。

提供源码 tag、发行版对应的 AMD64/ARM64 独立二进制、DEB/RPM 及 SHA256SUMS。安装匹配的发行版包，然后运行 `linux-factory-reset gui`；原 `ubuntu-reset` 命令仍兼容。

## English

This preview adds automatic official-source recovery for generic Ubuntu UEFI targets, independent rescue and failure/interruption rollback, and a real Fedora dracut recovery engine. The main application remains C++20, with a shared AMD64/ARM64 interface and automatic official URLs/checksums.

Actual AMD64 UEFI VMs for Ubuntu 26.04, Debian 13 and Fedora 45 completed official download, verification, offline restore, reboot, old-user/file removal, new-administrator setup and real sudo checks. Fedora keeps SELinux Enforcing and supports its kmscon console during initial setup. ARM64 has native build and actual official-image conversion evidence, without guest-boot or physical-hardware validation. See the [acceptance record](../validation/v0.5.0-alpha.1.md) for fault results and artifact provenance.

A temporary EFI entry boots independent kernel/initramfs copies from the ext4 recovery disk. The offline rollback copy is completed before root/ESP modification. Write failure rolls back; a durable recovery journal handles interruption. Completed recovery removes temporary personal backups and host recovery copies. ESPs containing another OS/vendor's boot files are rejected before restoration.

**Preview limits:** plain ext4 root + dedicated FAT ESP, standard GRUB and Secure Boot already disabled. No automatic partitioning, formatting or Secure Boot changes. Generic sources are Ubuntu Server / Debian NoCloud / Fedora Cloud Base, **without a desktop or exact historical desktop reconstruction**. Fedora Btrfs source conversion does not enable Btrfs targets. LVM, encryption, extra system partitions, installer-ISO automation and Mint remain unsupported. Native Ubuntu Pi boot retains its earlier flow. This is not secure erasure, A/B boot management or a universal hardware/power-loss transaction guarantee.

Source tag, distro-specific AMD64/ARM64 standalone binaries, DEB/RPM packages and SHA256SUMS are provided. Install the matching distro package and run `linux-factory-reset gui`; the legacy `ubuntu-reset` command remains compatible.
