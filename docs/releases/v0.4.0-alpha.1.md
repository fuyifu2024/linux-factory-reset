# Linux Factory Reset v0.4.0-alpha.1

## 中文

开发预览版。C++20 主程序，恢复阶段使用少量 Shell；源码、AMD64/ARM64 二进制和 Debian/Ubuntu DEB 一并提供。

- 修复真实磁盘镜像导入：显式要求 `lsblk` 返回分区树，避免 PATH 列输出平面 JSON 时误报“找不到 ext4/FAT 分区”。
- 修复精简 initramfs 环境的工具缺失与镜像回环挂载兼容问题，并在设置恢复标记前检查所需工具是否已打包。
- 加入 Debian 13 通用 AMD64/ARM64 UEFI 官方 NoCloud 恢复来源。界面自动选源，显示下载大小、百分比、平均速度、预计剩余时间并支持取消；特权导入前再次核对暂存镜像的 SHA-512。
- **Debian 自动来源为不带桌面的基础系统**，恢复后在本地控制台创建新管理员；不声称重现本机最初的桌面软件和配置。普通 Ubuntu UEFI 仍需匹配的已安装系统镜像；原生 Ubuntu 来源使用签名校验。
- 核对真实源分区的 PARTUUID/LABEL 与文件系统 UUID，将 GRUB 内核根参数转换为恢复目标 UUID，避免沿用镜像原分区标识。
- 锁定出厂镜像中的 root 凭据，隔离系统自带的首次设置向导与本项目开户流程；在设置恢复标记前重新检查旧恢复资料。旧资料不符合新版要求时须重新准备，不能直接沿用。

保留 v0.3 的统一界面、虚拟 GPU 软件绘制、缺失状态引导、恢复盘子文件夹识别，以及 Ubuntu/Debian/Fedora 官方 ISO 下载。下载 ISO 与自动恢复是不同能力：ISO 自动安装、Fedora 恢复引擎、Mint 尚未实现。恢复不是断电事务或安全擦除；仅支持已声明的 ext4 根分区 + FAT 启动分区布局。

## English

Development preview with a C++20 application and small Shell recovery scripts. Source, AMD64/ARM64 binaries and distro-specific Debian/Ubuntu DEBs are provided together.

- Fix partitioned-image import by explicitly requesting an `lsblk` JSON tree; PATH-only output otherwise produced a flat array and falsely rejected valid ext4/FAT images.
- Bundle required initramfs utilities explicitly, avoid the unavailable `wc` dependency, and create read-only loop devices explicitly instead of relying on mount auto-loop support. Required utilities are checked before reset is armed.
- Add official Debian 13 NoCloud sources for generic AMD64/ARM64 UEFI, automatic source selection, visible bytes/percentage/average speed/ETA and cancellation. The privileged importer checks the snapshotted file against the expected SHA-512 again.
- **The Debian source is a base system without a desktop**, followed by local-console administrator creation. It is not a historical reconstruction of the original desktop installation. Generic Ubuntu UEFI still requires a matching installed-system image; native Ubuntu sources use signed metadata.
- Verify source PARTUUID/LABEL identities and normalize GRUB kernel root arguments to the destination filesystem UUID.
- Lock factory root credentials, prevent competing firstboot wizards, and re-audit legacy profiles before arming reset. Profiles that fail the newer checks must be prepared again.

Retains the unified GUI, software rendering, guided missing-state/storage handling and official Ubuntu/Debian/Fedora ISO downloads. Automatic ISO installation, the Fedora restore engine and Mint integration remain unimplemented. Restoration is neither power-failure transactional nor secure erasure, and only the declared ext4-root/FAT-boot layout is supported.
