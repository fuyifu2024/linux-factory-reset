# Linux Factory Reset v0.3.0-alpha.1

## 中文

项目更名为 **linux-factory-reset**，原 `ubuntu-reset` 命令保持兼容。本版仍为开发预览。

- 新增 Ubuntu、Debian、Fedora 官方 ISO 下载；官网自动解析地址和 SHA-256，支持 AMD64 / ARM64。下载显示百分比、大小、平均速度、预计剩余时间，可取消，校验失败不保存最终文件。
- 统一界面，不单列板卡；普通操作无需输入“可信 HTTPS 地址”。本地 IMG / RAW / XZ / 独立 QCOW2 / 项目 Squashfs 可作为符合布局要求的恢复来源。
- 修复未准备恢复资料时的 `Cannot inspect ...state.json`；查看变更会说明准备步骤。选择恢复分区内子文件夹会自动定位挂载点；选到系统盘会说明第二块恢复盘要求。
- GUI 默认 Cairo / 软件绘制，以避开虚拟机 EGL / Zink 驱动问题；实际后端错误可以直接复制。
- 限制本地镜像快照、解压输出，拦截越出参照/暂存树的路径，补齐 fstab / GRUB / Pi 引导占位符及恢复前容量检查。

**边界：**官网下载 ISO 与自动恢复是两个能力。ISO 自动安装、Fedora 恢复引擎、Mint 尚未实现。Debian/Ubuntu ext4 + FAT 标准 UEFI 后端仍需干净已安装系统镜像；原生 Ubuntu 自动来源按硬件识别。没有完成真实 VM / 硬件重启恢复验收，也不保证断电恢复或磁盘安全擦除。ISO 下载器使用官方 HTTPS 校验值，本版不核对独立 PGP 签名。

包按 Debian 12、Debian 13、Ubuntu 24.04 与 AMD64 / ARM64 分开提供。选择匹配的 `.deb` 后执行：

```sh
sudo apt install ./linux-factory-reset_*.deb
linux-factory-reset gui
```

源码见下方自动生成的 Source code 存档；独立二进制、DEB 和 SHA256SUMS 为本版发布附件。内部 `/etc/ubuntu-reset`、hook 与恢复盘目录保留旧名以兼容已有资料。

## English

Renamed to **linux-factory-reset**, with the legacy `ubuntu-reset` command retained. This remains a development preview.

- Official Ubuntu, Debian and Fedora ISO downloads for AMD64/ARM64, using automatically resolved HTTPS metadata and SHA-256. Progress includes bytes, percentage, average speed, ETA and cancellation. Failed checksums never become final files.
- Unified hardware-independent interface; no custom URL required in normal setup. Compatible pristine installed-system IMG/RAW/XZ/standalone QCOW2/project Squashfs files can be imported.
- Guided missing-state handling; recovery subfolders resolve to their filesystem mountpoint; selecting the system filesystem explains the separate recovery-disk requirement.
- Cairo/software GUI rendering for virtual GPU compatibility; actual backend diagnostics are displayed.
- Bound image snapshots/decompression, reject escaping symlink paths, validate all boot relocation placeholders, and make capacity checks fail closed.

**Limits:** ISO downloads do not constitute automatic restoration. Automatic ISO installation, the Fedora reset engine and Mint integration are not implemented. The experimental Debian/Ubuntu ext4 + FAT UEFI backend still requires a pristine installed-system source. Native Ubuntu firmware sources are detected internally. Real VM/hardware reboot-and-restore acceptance, power-loss recovery and secure erasure are not established. ISO checksums come from official HTTPS metadata; detached PGP signatures are not checked by this downloader.

Choose a matching Debian 12, Debian 13 or Ubuntu 24.04 DEB for AMD64/ARM64. Source archives, standalone binaries, packages and SHA256SUMS are attached. Internal legacy state/hook/recovery-directory names are retained for upgrade compatibility.
