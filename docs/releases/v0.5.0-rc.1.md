# Linux Factory Reset v0.5.0-rc.1

## 中文

首个正式版候选，重点减少无效下载和准备失败：

- 新增“检查兼容性”和 `linux-factory-reset check [--storage /mnt/recovery]`，只读检查发行版、启动方式、目标布局、共享 ESP 和所选恢复盘。不创建恢复目录，不设置恢复标记，不修改固件。
- 图形界面自动准备在下载大镜像前先验证目标与恢复盘；检查失败立即展示实际原因，停止后续下载。
- 官方元数据请求增加 90 秒总超时，避免连接仍有少量数据时无限等待；大镜像保留进度、速度、取消和停滞超时。下载 User-Agent 使用实际程序版本。
- 普通用户遇到权限不足时可用 `sudo linux-factory-reset check` 只读重试。布局初检不等于完整恢复就绪；镜像、回退空间、Secure Boot 和引导检查仍以正式恢复前检查为准。

发布包含源码、八个独立二进制、六个 DEB、两个 RPM 和 SHA256SUMS。新测试、实际恢复结果与沿用基线见 [RC.1 验证记录](../validation/v0.5.0-rc.1.md)。[公测指南](../beta-testing.md) · [正式版验收清单](../stable-readiness.md)。

仍为预发布：物理硬件、Fedora ARM64 完整恢复未验收。支持范围继续限定为平铺 ext4 根分区、专用 FAT ESP、标准 GRUB、AMD64/ARM64 UEFI、Secure Boot 已关闭，另有 ext4 恢复盘。自动来源不带桌面；确认恢复会删除全部旧用户和目标个人文件。Mint、安装 ISO 自动部署、Btrfs 目标、LVM/加密/RAID、独立 `/boot` 或 `/home`、共享/OEM ESP 不支持。原生非 UEFI 板卡引导须单独验证。本工具不提供病毒检测、固件感染清除或安全擦除保证。

## English

The first release candidate focuses on avoiding wasted downloads and preparation failures:

- Add a GUI compatibility check and `linux-factory-reset check [--storage /mnt/recovery]`. It inspects distribution, boot/layout, shared ESP restrictions and the selected recovery volume without creating recovery directories, scheduling a reset or changing firmware.
- GUI automatic preparation validates the target and recovery volume before downloading a large image. Failure shows the actual reason and stops the download flow.
- Bound official metadata lookups to 90 seconds overall. Large images retain progress, speed, cancellation and stall timeouts. The download User-Agent now identifies the actual application version.
- If access is denied, retry the read-only check with `sudo`. Layout compatibility is not full restoration readiness: image integrity, rollback capacity, Secure Boot and boot preparation remain subject to final checks.

Assets include source, eight standalone executables, six DEBs, two RPMs and SHA256SUMS. See the [RC.1 validation record](../validation/v0.5.0-rc.1.md), [testing guide](../beta-testing.md) and [stable-release checklist](../stable-readiness.md).

This remains a prerelease. Physical hardware and full Fedora ARM64 restoration remain unverified. Scope is plain ext4 root, dedicated FAT ESP, standard GRUB, AMD64/ARM64 UEFI, Secure Boot already disabled, and another ext4 recovery volume. Automatic sources have no desktop; confirmed restoration deletes all old users and target personal data. Mint, automatic installer-ISO deployment, Btrfs targets, LVM/encryption/RAID, separate `/boot` or `/home`, and shared/OEM ESPs remain unsupported. Native non-UEFI board boot requires separate validation. This tool does not provide malware detection, firmware-infection removal or secure-erasure guarantees.
